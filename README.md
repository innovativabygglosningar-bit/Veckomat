# Veckans middagar

Delad veckomatsedel för hushållet: slumpa veckans middagar, byt enskilda dagar, betygsätt rätter och bocka av en gemensam handlingslista.

- `index.html` – hela appen
- `recipes.json` – receptbanken (ändringar i appen sparas ovanpå i databasen)
- `config.js` – Firebase-uppgifter
- `firestore.rules` – åtkomstregler för Firestore
- `sw.js`, `manifest.webmanifest`, `icons/` – gör appen installerbar och användbar offline

Publiceras med GitHub Pages från grenen `main`.
